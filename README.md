# PortalCyber360

Site institucional da **cybersec360** — https://cybersec360.com.br

Site estático (HTML + CSS + JS), hospedado no GitHub Pages a partir da branch `main`.

## Como editar

- Textos: `index.html` e `privacidade.html`
- Cores e layout: `assets/css/style.css` (cores no topo, em `:root`)
- Imagens: `assets/img/`
- E-mail que recebe o formulário de contato: `assets/js/main.js` (`EMAIL_DESTINO`)

Qualquer alteração enviada para a branch `main` é publicada automaticamente em 1–2 minutos.
